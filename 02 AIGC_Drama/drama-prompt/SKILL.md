# drama-prompt（即梦提示词升级版）

本 skill 是 `jimeng-prompt`（原 01-Aigc 项目）的升级版，定位为可触发的 CodeBuddy skill。

## 解决的痛点

原项目生成的结果是「7 个维度各随机抽一条」直接直出，带来的两个问题：

1. **画面元素过多、繁杂** —— 一次性把所有维度堆上去，观感杂乱。
2. **维度之间违和** —— 例如「汉服仙女 + 赛博朋克机甲 + 蒙古草原」，题材互相打架。

本升级版的思路（随机筛选模型）：

- 每次广撒一批**候选参数组合**，每个组合仍按 01-Aigc 方案**从每个维度各取一个值（7 维全取，不做子集裁剪）**，且**每图必含 1 条随机运镜**；
- 再用 `-hl`（严谨度）对这批组合打分，**只输出「最合适几个」组合**，自动剔除违和项 —— 让画面焦点集中、不再杂乱矛盾。

> 一句话：**随机筛选 = 按维度全选组成候选 + 按 `-hl` 一致性打分只留最协调的几个**，而不是整行预设直出。

## 参数表来源（唯一数据源）

运行时只加载构建好的 `data/params.json`，其由两份 xlsx 经 `build_data.py` 解析生成：

| 参数表 | 文件 | 用途 |
| --- | --- | --- |
| 即梦800个神级指令合集 | `data/即梦800个神级指令合集.xlsx` | 7 维度池（风格/镜头/人物/场景/细节/色调/文化） |
| 运镜方式 | `data/运镜方式.xlsx` | 运镜池（`中文名称` + `详细解释`，每图必含 1 条） |

维度映射（key=内部键，label=表头列名）：

```
style=风格与艺术表现  lens=镜头与构图  character=人物与服饰(主体回退源)
scene=场景与背景      detail=细节与服饰  tone=色调与光效  culture=文化与环境
```

> `character`（人物与服饰）维度不参与随机，而是作为**画面主体的回退来源**：用户给主体用用户的，不给则从该列随机取一条当主体。

## 用法

```bash
python scripts/generate.py "一只羊"
python scripts/generate.py "修仙者" -hl 10            # 最严谨：硬过滤 + 大候选 + 多轮重抽
python scripts/generate.py "修仙者" -hl 0              # 最松：纯随机，会出现题材矛盾
python scripts/generate.py "一个东方美女" -n 5 -hl 8 --seed 42
python scripts/generate.py "一只羊" --raw              # 逗号拼接的原始形态
python scripts/generate.py "一只羊" -n 3 --json        # 结构化输出
# 紧凑写法（等价）
python scripts/generate.py h8 n5 修仙者                # -hl 8 -n 5 修仙者
python scripts/generate.py 抽3 一只羊                  # -n 3 一只羊
```

### 参数

| 参数 | 说明 |
| --- | --- |
| `subject` | 画面主体（位置参数，可选）；省略则随机取自「人物与服饰」维度 |
| `-hl N` / `hN` | 严谨度 0-10，默认 5；0=纯随机不检查，10=最严（题材硬过滤+大候选+多轮重抽） |
| `-n N` / `nN` / `抽N` | 输出条数，默认 1 |
| `--seed` | 随机种子，复现同一组组合 |
| `--raw` | 输出逗号拼接的原始形态（不含运镜行） |
| `--no-suffix` | 不追加画质后缀 |
| `--json` | 结构化输出（含每组合的 penalty 与 values） |
| `--no-consistency` | 等价 `-hl 0` |

> 严谨度机制（`Judge`/`penalty`/`consistency.json`）完整沿用 jimeng-prompt，确保 `-hl` 语义一致：0 纯随机、10 最严题材硬过滤 + 大候选量 + 多轮重抽。

## 输出示例

```
【提示词】竖屏 9:16 画幅，一只羊，创作风格为超写实风格，镜头以剪影镜头取景，背景处于沙漠鲸鱼骨骸，细节表现蛛网露珠银链，整体光影为神秘的紫色光辉，空间里透着夏威夷火山口的神圣祭祀场的气质，高清细节，电影级质感。
【运镜】失焦镜头：故意将摄像机焦点设置得不清晰，使画面模糊。
【维度拆解】人物与服饰=一只羊（主体） | 风格与艺术表现=超写实风格 | 镜头与构图=剪影镜头 | 场景与背景=沙漠鲸鱼骨骸 | 细节与服饰=蛛网露珠银链 | 色调与光效=神秘的紫色光辉 | 文化与环境=夏威夷火山口的神圣祭祀场 | 运镜=失焦镜头
【一致性】严谨度 hl=8/10 · 协调评分 0（从 440 组候选中筛选，分越低越协调）
```

- 运镜**必含**，以独立【运镜】行输出（名称 + 详细解释）。
- `-hl` 越高，候选量越大、重抽轮数越多、且对与主体题材互斥的取值做硬过滤；分越低越协调。

## 与原 jimeng-prompt 的区别

| 项 | jimeng-prompt（01-Aigc） | drama-prompt（02-Aigc，本 skill） |
| --- | --- | --- |
| 运镜 | 默认关闭，需 `-con` 才启用 | **每图必含 1 条** |
| 视频/口播 | 支持 `-s` 视频、`-kon` 口播 | 聚焦图片提示词，不内置视频/口播 |
| 目标 | 通用随机组合 | 专治「元素过多」+「维度违和」，按 `-hl` 择优只输出最协调几个 |
| 参数表解析 | openpyxl（构建期） | 标准库 `zipfile`（构建期），运行时零第三方依赖 |
| 触发 | /jimeng-prompt | /drama-prompt |

## 重建参数表

当两份 xlsx 更新后，重跑构建脚本即可刷新 `data/params.json`：

```bash
python scripts/build_data.py
python scripts/build_data.py --no-filter   # 保留原始全部条目（关闭内容安全过滤）
```

## 目录结构

```
drama-prompt/
├── SKILL.md
├── scripts/
│   ├── build_data.py     # zipfile 解析两个 xlsx -> data/params.json
│   └── generate.py       # 全维度候选 + 运镜必含 + Judge 评价择优 + 渲染输出
└── data/
    ├── params.json                 # 由 xlsx 生成：7 维度池 + 运镜池(中文名+解释)
    ├── consistency.json            # 题材一致性规则（沿用 jimeng-prompt）
    ├── templates.json              # 自然语言重写模板（沿用 jimeng-prompt）
    ├── 即梦800个神级指令合集.xlsx   # 参数表（原表复制）
    └── 运镜方式.xlsx                # 参数表（原表复制）
```
