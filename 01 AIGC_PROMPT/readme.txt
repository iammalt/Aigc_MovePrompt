====================================================================
即梦提示词随机组合 Skill —— 想法与设计说明
====================================================================

一、原始想法
--------------------------------------------------------------------
本目录下的《即梦800个神级指令合集.xlsx》是一张提示词词库表：

    第 2 行是表头，7 个维度列分别为
        风格与艺术表现 / 镜头与构图 / 人物与服饰 / 场景与背景 /
        细节与服饰 / 色调与光效 / 文化与环境
    第 3~115 行是数据，共 113 条，每个维度列各有 113 个具体条目。

想法是：把这张表做成一个可复用的 skill。
当我调用它并输入一个画面主体（比如"一只羊""一个东方美女"）时，
它从每个维度里随机取出一个具体条目，组合成一条用于生成图片的提示词。
也就是说，同一个主体每次调用都能得到风格、镜头、场景、细节、色调、
文化背景各不相同的画面方案，用来快速刷灵感、找方向。

二、已实现的方案
--------------------------------------------------------------------
skill 名称：jimeng-prompt
安装位置：C:\Users\27925\.codebuddy\skills\jimeng-prompt
        （用户级 skill，全局可用，与本机既有的 keil、workflow 同级）

1. 主体替换规则
   「人物与服饰」这一列不参与随机，直接由我输入的主体占据。
   原因是随机会抽出"穿白色婚纱的女子"这类条目，与"一只羊"语义冲突。

2. 自然语言重写
   不再输出逗号堆砌的词条串，而是按每个维度的语义套用句式，
   重写成一段连贯的中文描述，更符合生图模型的理解方式。
   举例：

       【提示词】一只羊，以卡通风格呈现，采用特写镜头构图，主体置身于
       沙漠中的古老庙宇，细节处刻画手工织布机的木质齿轮，暖色调的夕阳
       营造画面氛围，环境融入阿尔卑斯山的滑雪度假村的文化气息，
       高清细节，电影级质感。
       【维度拆解】人物与服饰=一只羊（主体） | 风格与艺术表现=卡通风格 |
       镜头与构图=特写镜头 | 场景与背景=沙漠中的古老庙宇 |
       细节与服饰=手工织布机的木质齿轮 | 色调与光效=暖色调的夕阳 |
       文化与环境=阿尔卑斯山的滑雪度假村

   【提示词】一行是可以直接粘贴进即梦的成品；
   【维度拆解】一行用于复现和调参（想换掉某一维度时直接改那一项）。

3. 句式变体
   每个维度准备了 4 种句式随机选用，例如"细节与服饰"可以是
   "细节处刻画{v}""画面细节聚焦{v}""细节表现{v}""细微之处可见{v}"，
   因此一次生成多条方案时，句子结构不会雷同。

4. 一次多条且互不重复
   默认生成 1 条；指定 -n 5 则一次给出 5 条方案，
   同一批次内每个维度不重复抽同一个条目。

5. 可选运镜维度
   《运镜方式.xlsx》（69 条）作为第 8 维度并入，但默认关闭，
   只有显式加 --camera 时才随机抽 1 条运镜。

6. 可复现
   提供 --seed 参数，固定种子后同一组组合可以完全重现。

三、使用方式
--------------------------------------------------------------------
在对话里直接说需求即可（skill 会自动触发）：

    "用即梦给我出 5 张一只羊的图，随机组合"
    "帮我生成 3 个东方美女的提示词，加上运镜"
    "随机来几个赛博朋克风格的城市画面方案"

底层脚本也可直接调用：

    python C:\Users\27925\.codebuddy\skills\jimeng-prompt\scripts\generate.py "一只羊"
    python ...\generate.py "一个东方美女" -n 5
    python ...\generate.py "一只羊" -n 3 --camera
    python ...\generate.py "一只羊" --seed 42        # 复现同一组
    python ...\generate.py "一只羊" --raw            # 逗号拼接的原始形态
    python ...\generate.py "一只羊" --no-suffix      # 去掉画质后缀
    python ...\generate.py "一只羊" -n 3 --json      # 结构化输出
    python ...\generate.py "修仙者" -hl 10            # 最严谨，反复重抽直到协调
    python ...\generate.py "修仙者" -hl 0             # 最松，纯随机不检查

可选参数：-n/--count 条数、-hl 严谨度(0-10)、--camera 启用运镜、--seed 随机种子、
--raw 原始形态、--no-suffix 关闭画质后缀、--json 结构化输出、
--candidates 候选组合数、--retries 重抽轮数、--no-consistency 关闭一致性校验。

紧凑写法（脚本会自动展开，不用记标准参数名）：

    h8 / hl8 / -h8   ->  -hl 8
    n3               ->  -n 3
    抽3              ->  -n 3

所以 "h8 抽3修仙者" 等价于 -n 3 -hl 8，主体为"修仙者"；
脚本可以直接这样调用：

    python ...\generate.py h8 n3 修仙者

如果完全不给主体（例如 "h3 抽3次"），主体会自动从「人物与服饰」这一列
随机抽取，同一批次内不重复，输出里会标注"随机主体"：

    【主体】未提供主体，已随机取自「人物与服饰」维度（同批次内不重复）。

此时抽出来的人物本身也会参与一致性打分，所以场景、风格、文化背景会
跟着这个人物走（例如抽到"印度纱丽数学女神"，就容易配到印度细密画风格）。

四、数据来源与维护
--------------------------------------------------------------------
数据源（本目录）：
    即梦800个神级指令合集.xlsx   7 个维度 × 113 条
    运镜方式.xlsx                69 条运镜

构建时会做清洗：去除 UTF-8 BOM 字符（\ufeff，表里位置随机且可能重复）、
去除首尾空格与全角空格、压缩内部空白、跳过空行、同一维度去重并保持原序。
另外内置了一道内容安全词过滤：原表中有"全息烟花妓院"这类条目，直接拿去生图
会被平台审核拦截。命中词表的条目在构建时被丢弃并打印明细；若确需保留原始
全部条目，构建时加 --no-filter。
清洗结果固化为 JSON，运行时直接读 JSON，不再依赖 Excel，也不需要
openpyxl（只有重建数据时才需要）。

表格内容更新后，重跑一次即可刷新词库：

    python C:\Users\27925\.codebuddy\skills\jimeng-prompt\scripts\build_data.py
    python ...\build_data.py --jimeng "新表路径.xlsx" --camera "运镜表路径.xlsx"

六、一致性改造（解决"场景太矛盾"）
--------------------------------------------------------------------
最初版本是纯随机：每个维度独立抽一条，组合起来经常荒唐，例如
"修仙者 + 记忆黑市交易所"、"小猫钓鱼 + 废弃卫星坠落带"。
根源是这张表把现实、自然、科幻、超现实题材混在同一个池子里，
纯随机命中同题材的概率不高。

现在改成两步：

1. 题材硬过滤
   先从主体推断题材（"修仙者"→东方古典、"小猫钓鱼"→自然生趣、
   "赛博机甲"→科幻超现实），把与之直接互斥的取值踢出候选池。
   例如输入"修仙者"时，科幻超现实、都市现代、西方古典的场景与
   文化条目不再参与抽取。

2. 候选打分 + 自动重抽
   每轮先抽 36 组（可用 --candidates 调整）候选，按互斥关系打分，
   取分最低的一组；若一批里没有理想组合（评分 ≤ 0），自动再抽一批，
   最多 --retries 轮（默认 3）。这就是"不合理就重新抽卡"。

输出里多了一行，可以直观看到筛选强度：

    【一致性】协调评分 -4（从 108 组候选中筛选，分越低越协调）

评分为负 = 主体与场景/风格/文化题材互相呼应；
0 = 各维度之间无语义冲突；正数 = 仍有题材冲突。

判断口径全部写在 data\consistency.json 里（题材关键词、互斥表、
主体题材提示词），想放宽或收紧，直接改这个文件即可，不用改代码。
改完可以跑诊断脚本看词条标签覆盖率：

    python C:\Users\27925\.codebuddy\skills\jimeng-prompt\scripts\_check_themes.py

想完全回到纯随机（接受矛盾组合），加 --no-consistency：

    python ...\generate.py "修仙者" --no-consistency

效果对比（同一主体、同一 seed）：
    开启一致性：水墨插画风格 + 中国的园林景观 / 哥窑开片釉裂 + 秘鲁马丘比丘
    关闭一致性：星际垃圾回收环 + 维也纳金色大厅 / 永夜极光观测台

注意：硬过滤会缩小候选池，因此某些主体下 -n 的可用上限会随之变化，
超出时脚本会给出明确提示。

严谨度等级 -hl（0-10，默认 5）
--------------------------------------------------------------------
-hl 把"要多严格"翻译成三个具体参数：是否校验、是否题材硬过滤、
每轮候选数与重抽轮数。

    等级     一致性校验   题材硬过滤   每轮候选数   重抽轮数   说明
    0        关          关          ——          ——       纯随机，接受任何矛盾组合
    1-2      开          关          12-24       1-2      只按打分选最优，保留跨题材创意
    3-7      开          开          36-84       3-7      默认 5：先剔除互斥题材再选优
    8-10     开          开          96-120      8-10     最严谨，反复重抽直到协调

候选数还会被维度池上限裁剪；--candidates / --retries 可覆盖 -hl 推导值。
输出里会显示当前等级：

    【一致性】严谨度 hl=10/10 · 协调评分 -4（从 190 组候选中筛选，分越低越协调）

若一轮下来没找到协调组合（最佳评分仍为正），末尾会提示提高 -hl 重试。
