# 即梦提示词随机组合器

把「即梦800个神级指令合集」表格变成随机灵感引擎：给定一个画面主体，按维度随机抽词，重写成自然语言提示词。

## 命令

```bash
python <skill-dir>/scripts/generate.py "一只羊"                 # 生成 1 条
python <skill-dir>/scripts/generate.py "一个东方美女" -n 5       # 生成 5 条互不重复的方案
python <skill-dir>/scripts/generate.py "一只羊" -n 3 --camera    # 额外随机叠加一条运镜
python <skill-dir>/scripts/generate.py "修仙者" -hl 10 --camera    # 最严谨 + 运镜
python <skill-dir>/scripts/generate.py "未来机器人" -s 8            # 视频 8 秒
python <skill-dir>/scripts/generate.py "一只羊" -s 15 -n 2          # 视频 15 秒，2 条
python <skill-dir>/scripts/generate.py "修仙者" -n 3 -con           # 开启运镜方式
python <skill-dir>/scripts/generate.py "一只羊" --seed 42        # 复现同一组组合
python <skill-dir>/scripts/generate.py "一只羊" --raw            # 逗号拼接的原始形态
python <skill-dir>/scripts/generate.py "一只羊" --no-suffix      # 去掉画质后缀
python <skill-dir>/scripts/generate.py "修仙者" -hl 10           # 升级模式：运镜自动必含 + 最严筛选（无需再加 -con）
python <skill-dir>/scripts/generate.py "修仙者" -hl 1            # 宽松：保留跨题材创意，只按打分选优
python <skill-dir>/scripts/generate.py "修仙者" -hl 0            # 最松：纯随机，不检查题材
python <skill-dir>/scripts/generate.py "修仙者" --no-consistency # 与 -hl 0 等价
python <skill-dir>/scripts/generate.py -n 3 -hl 3             # 不给主体，自动随机人物
python <skill-dir>/scripts/generate.py h3 抽3次                # 与上一条等价
python <skill-dir>/scripts/generate.py "一只羊" -n 3 --json      # 结构化输出
```

`<skill-dir>` 指本 skill 目录（含本 `SKILL.md` 的目录），例如 `C:\Users\27925\.codebuddy\skills\jimeng-prompt`。

## 参数

| 参数 | 说明 |
| --- | --- |
| `subject`（位置参数，可省略） | 画面主体，如 `"一只羊"`；省略时自动从「人物与服饰」维度随机抽取 |
| `-n, --count` | 生成条数，默认 1；同批次内同一维度不重复抽同一条目 |
| `-con, --camera` | 开启运镜方式（默认不开启）；视频模式自动启用 |
| `-kon, --kon` | 开启自媒体口播文案（**默认关闭**） |
| `-s, --seconds` | 视频时长（秒），5-120；给值后输出视频提示词而非图片 |
| `--seed` | 随机种子，用于复现 |
| `-hl, --hl` | **严谨度等级 0-10**，默认 5。0 = 不检查纯随机，10 = 最严谨（题材硬过滤 + 大候选量 + 多轮重抽）。**指定 10 时自动进入「升级模式」：运镜必含 + 最严筛选，无需再加 `-con`** |
| `--raw` | 输出逗号拼接的原始词条形态（不推荐，作为兼容入口） |
| `--no-suffix` | 不追加画质后缀「高清细节，电影级质感」 |
| `--json` | 以 JSON 结构化输出，便于二次处理 |
| `--candidates` | 每轮抽取的候选组合数，给值后覆盖 `-hl` 的推导值 |
| `--retries` | 重抽轮数，给值后覆盖 `-hl` 的推导值 |
| `--no-consistency` | 等价于 `-hl 0`，关闭一致性校验与题材过滤，退回纯随机 |

## 紧凑写法

脚本层已内置简写展开，下面两种写法完全等价：

```bash
python <skill-dir>/scripts/generate.py h8 n3 修仙者
python <skill-dir>/scripts/generate.py "修仙者" -n 3 -hl 8
```

| 简写 | 等价 |
| --- | --- |
| `h8` / `hl8` / `-h8` | `-hl 8` |
| `n3` | `-n 3` |
| `s8` / `-s8` | `-s 8（视频 8 秒）` |
| `con` / `-con` | `-con（开启运镜）` |
| `kon` / `-kon` | `-kon（开启口播文案）` |
| `抽3` / `抽3次` | `-n 3` |

### 自然语言指令的解析规则（模型侧）

用户可能把简写与主体粘连在一起，例如「h8 抽3修仙者」「hl0 一只羊」「n5 一个东方美女」。按以下规则拆：

1. `h<数字>` / `hl<数字>` → `-hl <数字>`
2. `n<数字>` → `-n <数字>`
3. 中文里的「抽<数字>」「来<数字>个」「要<数字>条」「<数字>个方案」→ `-n <数字>`，去掉数字与量词后剩余部分作为主体
4. 其余文字作为画面主体（subject）

示例：

| 用户输入 | 实际执行 |
| --- | --- |
| `h8 抽3修仙者` | `python ... generate.py "修仙者" -n 3 -hl 8` |
| `hl0 一只羊` | `python ... generate.py "一只羊" -hl 0` |
| `n5 一个东方美女 -con` | `python ... generate.py "一个东方美女" -n 5 -con` |
| `h10 抽1小猫钓鱼` | `python ... generate.py "小猫钓鱼" -n 1 -hl 10` |
| `h3 抽3次`（无主体） | `python ... generate.py -n 3 -hl 3`，主体自动从「人物与服饰」抽取 |

## 输出格式

默认文本输出（单条）：

```
【提示词】一只羊，以卡通风格呈现，采用特写镜头构图，主体置身于沙漠中的古老庙宇，细节处刻画手工织布机的木质齿轮，暖色调的夕阳营造画面氛围，环境融入阿尔卑斯山的滑雪度假村的文化气息，高清细节，电影级质感。
【维度拆解】人物与服饰=一只羊（主体） | 风格与艺术表现=卡通风格 | 镜头与构图=特写镜头 | 场景与背景=沙漠中的古老庙宇 | 细节与服饰=手工织布机的木质齿轮 | 色调与光效=暖色调的夕阳 | 文化与环境=阿尔卑斯山的滑雪度假村
```

多条时每条带 `方案 i/N` 标题，末尾附对应维度拆解。

启用一致性校验时还会多出一行：

```
【一致性】严谨度 hl=10/10 · 协调评分 -4（从 190 组候选中筛选，分越低越协调）
```

评分为负代表主体与场景/风格/文化题材互相呼应，`0` 代表各维度之间无语义冲突，正数代表仍存在题材冲突（越大越矛盾）。若一轮下来没找到协调组合，末尾会提示提高 `-hl` 重试。

- `【提示词】` 是一段连贯中文自然语言，**可直接粘贴进即梦**，无需再加工。
- `【维度拆解】` 用于复现和调参（例如想换掉某个维度时，直接改那一项）。

## 工作流程（模型操作指引）

1. 从用户输入中提取**画面主体**。若用户没给主体（例如只说"抽3次""来几个方案"），**不要追问**，直接省略 subject 参数——脚本会自动从「人物与服饰」维度随机抽一条作为主体，同批次内不重复。
2. 判断条数：用户说"5 个方案"→ `-n 5`；未说明则用默认 1 条。
3. 判断是否启用运镜：用户明确提到运镜、镜头运动、推拉摇移时加 `--camera`，否则不加。
4. 调用 `generate.py` 并把脚本输出**原样呈现**给用户，不要把 `【提示词】` 里的措辞自行改写或"优化"，否则破坏可复现性。
5. 用户要求复现某次结果时，把当时的 `--seed` 一并带上。
6. 用户反馈"场景矛盾 / 不合理 / 重抽"时：提高严谨度重抽（`-hl 10`）；用户想要更野、更跨题材的组合时调低（`-hl 1` 或 `-hl 0`）；若仍不理想，再按用户指定的题材关键词人工约束（例如"场景限雪山或云海"）后重新调用，并说明被替换的维度。
7. 用户提到严谨度（"严格一点""随便抽就行""hl 8"）时映射到 `-hl` 对应数值；用户未提及则用默认 5。

## 维度与主体替换规则

- 表格共 7 个维度，其中**「人物与服饰」由用户输入的主体替换**，不参与随机（避免"一只羊"配上"穿白色婚纱的女子"这类语义冲突）。
- 其余 6 个维度（风格与艺术表现、镜头与构图、场景与背景、细节与服饰、色调与光效、文化与环境）各随机抽 1 条。
- 运镜为第 8 维度，默认关闭，需 `--camera` 显式启用；视频模式自动叠加。

## 句式模板

自然语言重写由 `data/templates.json` 驱动：每个维度提供 4 种句式变体，渲染时随机选用，因此同一维度在不同方案中措辞不同。

想调整措辞（比如把"细节处刻画{v}"改成"画面强调{v}"），直接编辑 `data/templates.json` 的 `slots` 段即可，无需改代码。`suffix` 字段控制画质后缀。

## 视频模式

加 `-s <秒数>`（5-120）即输出**视频提示词**：句式自动切换为动态描写、`-con`/`--camera` 自动叠加运镜、句末追加"视频时长约 N 秒"。

| 维度 | 图片模板 `slots` | 视频模板 `video.slots` |
| --- | --- | --- |
| 句式 | `slots` 静态描写 | `video.slots` 动态描写（"镜头缓缓带过…""光影贯穿整个镜头"） |
| 运镜 | 需 `-con`/`--camera` 才有 | **自动叠加**（视频通常要有镜头运动） |
| 画质后缀 | 高清细节，电影级质感 | 画面流畅稳定，运动自然 |
| 结尾 | — | 追加"视频时长约 N 秒" |

示例输出：

```
【视频提示词】一只羊，以卡通风格呈现，镜头缓缓带过特写构图，主体置身于沙漠中的古老庙宇，细节处刻画手工织布机的木质齿轮，暖色调的夕阳笼罩全局，环境融入阿尔卑斯山的滑雪度假村的文化气息，视频时长约 8 秒。
【维度拆解】人物与服饰=一只羊（主体） | 风格与艺术表现=卡通风格 | 镜头与构图=特写镜头 | 场景与背景=沙漠中的古老庙宇 | 细节与服饰=手工织布机的木质齿轮 | 色调与光效=暖色调的夕阳 | 文化与环境=阿尔卑斯山的滑雪度假村
```

想改视频措辞，编辑 `data/templates.json` 的 `video` 段即可，与图片模板互不影响。

## 自媒体口播文案

**默认不输出**；加 `-kon`（紧凑写法写作 `kon`）才附带一句 `【口播文案】`，用于自媒体运营：

- **贴合本次画面**：用当前抽到的主体、场景、色调、文化等维度拼出，不是通用套话
- **四类风格随机**：悬念钩子 / 情绪共鸣 / 反差设问 / 干货描述，每次换一种
- **可选引导收尾**：约 60% 概率追加一句（"这一幕值得你停下来看三秒。"等）

示例：

```
【口播文案】当浮世绘风格遇上传统的中国庭院，修仙者成了唯一的答案。
【口播文案】在熔岩流淌般的橙红光纹里，修仙者与夕阳下的海港安静地对望。别忘了看完再走。
```

话术模板在 `data/templates.json` 的 `copy` 段（含 `styles` 四类与 `tail` 收尾句），想改直接编辑，不用动代码。

## 数据维护

数据来自工作区 `01 AIGC_PROMPT/` 下的两个表格，已清洗并固化为 JSON，运行时不依赖 Excel：

```bash
python <skill-dir>/scripts/build_data.py                                   # 使用默认表格路径重建
python <skill-dir>/scripts/build_data.py --jimeng "D:/x/表.xlsx" --camera "D:/x/运镜.xlsx"
```

清洗规则：去除 UTF-8 BOM（`\ufeff`）、去除首尾空格与全角空格、压缩内部空白、跳过空行、同维度去重保序；并内置内容安全词过滤（原表中的"全息烟花妓院"这类条目会被图片平台审核拦截，构建时丢弃并打印明细），确需保留原始条目时加 `--no-filter`。

- `data/jimeng_prompts.json`：6 个可随机维度 + 被主体替代的 character 维度（各 113 条，去重后可能略少）
- `data/camera_moves.json`：69 条运镜中文名
- `data/templates.json`：句式模板与画质后缀
- `data/consistency.json`：题材簇关键词、互斥表、主体题材提示词（决定"合理性"的判断口径）

## 一致性校验（自动重新抽卡）

纯随机会把科幻场景配到仙侠主体上、把室内餐厅配到雪山背景上。为避免这种矛盾，生成分两步：

1. **题材硬过滤**：先从主体推断题材（"修仙者"→东方古典、"小猫钓鱼"→自然生趣、"赛博机甲"→科幻超现实），把与之直接互斥的取值踢出候选池。
2. **候选打分重抽**：每轮抽若干组候选，按 `consistency.json` 的互斥关系打分，取分最低的组合；若一批里没有理想组合（评分 ≤ 0），自动再抽一批。

### 严谨度等级 `-hl`（0-10）

| 等级 | 一致性校验 | 题材硬过滤 | 每轮候选数 | 重抽轮数 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 0 | 关 | 关 | — | — | 纯随机，接受任何矛盾组合 |
| 1-2 | 开 | 关 | 12-24 | 1-2 | 只按冲突打分选最优，保留跨题材创意 |
| 3-7 | 开 | 开 | 36-84 | 3-7 | 默认 5：先剔除互斥题材，再打分选优 |
| 8-10 | 开 | 开 | 96-120 | 8-10 | 最严谨：反复重抽直到找到协调组合 |

候选数还会被当前维度池的上限裁剪；`-hl` 推导出的值可被 `--candidates` / `--retries` 覆盖。

### 升级模式（`-hl 10` 专属）

当严谨度设为 **10** 时，skill 自动进入「升级模式」：

- **运镜必含**：无需再加 `-con` / `--camera`，结果自动叠加 1 条随机运镜（专治画面无镜头运动、观感死板）；
- **最严筛选**：题材硬过滤 + 大候选量（120）+ 多轮重抽（10 轮），直到抽到完全协调（评分 ≤ 0）的组合才停。

`0-9` 维持原模式：运镜默认关闭（需 `-con` 显式开启），筛选强度随等级递增但不强制运镜。即 `-h10`（紧凑写法）等价于「最严筛选 + 运镜必含」的一键组合；若显式加 `--no-consistency` 则跳过升级模式，退回纯随机。

想调整判断口径（例如去掉某条互斥关系、补充新的题材关键词），直接编辑 `data/consistency.json`，无需改代码。改完可用诊断脚本查看词条标签覆盖率：

```bash
python <skill-dir>/scripts/_check_themes.py
```
