# jimeng-prompt

即梦（Dreamina）生图提示词的随机组合器。

给它一个画面主体，它会从「即梦800个神级指令合集」的各个维度随机抽词，重写成一段连贯的中文提示词，可直接粘贴进即梦出图。

## 快速上手

```bash
python scripts/generate.py "一只羊"
python scripts/generate.py "一个东方美女" -n 5
python scripts/generate.py "一只羊" -n 3 --camera --seed 42
python scripts/generate.py "修仙者" -hl 10                # 最严谨：反复重抽到协调为止
python scripts/generate.py "修仙者" -hl 0                 # 最松：纯随机，不检查题材
python scripts/generate.py h8 n3 修仙者                   # 紧凑写法，等价 -n 3 -hl 8
python scripts/generate.py h3 抽3次                        # 不给主体，自动从人物与服饰抽
```

输出示例：

```
【提示词】一只羊，以卡通风格呈现，采用特写镜头构图，主体置身于沙漠中的古老庙宇，细节处刻画手工织布机的木质齿轮，暖色调的夕阳营造画面氛围，环境融入阿尔卑斯山的滑雪度假村的文化气息，高清细节，电影级质感。
【维度拆解】人物与服饰=一只羊（主体） | 风格与艺术表现=卡通风格 | 镜头与构图=特写镜头 | ...
```

完整参数说明、模型侧工作流程、模板定制方式见 [SKILL.md](SKILL.md)。

## 目录结构

```
jimeng-prompt/
├── SKILL.md                      # skill 定义与使用说明（模型读取入口）
├── README.md                     # 本文件
├── data/
│   ├── jimeng_prompts.json       # 清洗后的 7 维度词库（每维度 113 条）
│   ├── camera_moves.json         # 运镜中文名
│   ├── templates.json            # 自然语言句式模板与画质后缀
│   └── consistency.json          # 题材簇、互斥表、主体题材提示词
└── scripts/
    ├── build_data.py             # Excel -> 清洗 -> JSON（数据更新时重跑）
    ├── generate.py               # 题材过滤 + 随机组合 + 自然语言渲染
    ├── _check_themes.py          # 诊断：查看词条题材标签覆盖率
    └── fix_encoding.py           # 文本文件编码归一化为 UTF-8
```

## 设计要点

- **主体替换而非硬拼**：输入的主体直接占据「人物与服饰」维度，避免"一只羊 + 穿白色婚纱的女子"这类语义冲突。
- **自然语言重写**：不是词条逗号堆砌，而是按维度语义套用句式（`以{v}呈现`、`主体置身于{v}`、`细节处刻画{v}`……），更贴近生图模型的理解方式。
- **句式变体**：每个维度 4 种句式随机选用，多条方案之间措辞不雷同。
- **一致性校验**：先从主体推断题材并剔除互斥取值，再从多组候选中按冲突评分挑最协调的一组，避免"仙侠主体配科幻场景""室内餐厅配雪山背景"这类矛盾。
- **严谨度可调**：`-hl 0-10` 一键控制严格程度，0 是纯随机，10 是大候选量 + 多轮重抽直到协调，默认 5。
- **主体可省略**：不给主体时自动从「人物与服饰」维度随机抽一条作主体，同批次内不重复。
- **可复现**：`--seed` 固定后同一组组合可完全重现。
- **数据与代码分离**：词库和模板都是 JSON，改措辞不需要动代码。

## 数据更新

词库由工作区 `01 AIGC_PROMPT/` 下的 Excel 生成，更新表格后重跑：

```bash
python scripts/build_data.py --jimeng "路径/即梦800个神级指令合集.xlsx" --camera "路径/运镜方式.xlsx"
```

## 依赖

- Python 3.8+
- `openpyxl`（仅重建数据时需要）

## 数据来源

- `即梦800个神级指令合集.xlsx`（7 个维度 × 113 条）
- `运镜方式.xlsx`（69 条运镜）
